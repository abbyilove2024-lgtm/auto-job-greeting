# Security Policy

## Supported Version

Only the latest `main` branch is supported for security updates.

## Reporting a Vulnerability

If you discover a security issue, please do not publish it publicly first.

Recommended process:

1. Open a private security advisory on GitHub for this repository, if available.
2. If private advisory is unavailable, contact the repository owner directly before opening a public issue.

Please include:

- Affected file or module
- Reproduction steps
- Impact assessment
- Suggested mitigation (if any)

We will review and respond as soon as possible.
